Eir Open provides a suite of open source tools spanning medication databases, health data standards, and privacy-first applications. Each project is designed for seamless integration with AI agents, LLMs, and healthcare workflows.

<Aside type="tip" title="Get started in 30 seconds">
  <a href="/eir-open/docs/quickstart/">Quickstart</a> — Mac one-liner and individual installs.
  <a href="/eir-open/docs/agent-integration/">Agent Integration</a> — Claude, LangChain, and more.
  <a href="/eir-open/docs/cbt-programs/">CBT Programs</a> — modular, multilingual open CBT registry.
  <a href="/eir-open/docs/mcp-server/">MCP Server</a> — load health data into Claude Desktop.
  <a href="/eir-open/docs/openclaw-integration/">OpenClaw</a> — add skills to your agent.
</Aside>
