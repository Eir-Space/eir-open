This viewer is generated directly from `skills/cbt-programs/data/programs` in the repository.

Use it to:

- see what programs currently exist,
- filter by language,
- open and read full program content (summary, modules, exercises, homework),
- inspect lineage and translation status,
- open each program folder on GitHub.
