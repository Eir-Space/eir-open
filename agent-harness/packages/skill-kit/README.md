# @eir-open/skill-kit

Skill format specification, loader, and prompt assembly for health agents.

Part of the [@eir-open/agent-harness](https://github.com/Eir-Space/eir-open/tree/main/agent-harness) monorepo.

## Install

```bash
npm install @eir-open/skill-kit
```

## Usage

```typescript
import {
  loadSkill,
  loadSkillDirectory,
  getSkillsForMode,
  buildSkillPrompt,
  parseSkillMarkdown,
} from '@eir-open/skill-kit';
```

See the [full documentation](https://github.com/Eir-Space/eir-open/tree/main/agent-harness) for API details and examples.
