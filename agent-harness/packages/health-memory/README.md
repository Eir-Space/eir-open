# @eir-open/health-memory

Open Health Memory Standard — schemas, store interface, and reference implementation for structured health data.

Part of the [@eir-open/agent-harness](https://github.com/Eir-Space/eir-open/tree/main/agent-harness) monorepo.

## Install

```bash
npm install @eir-open/health-memory
```

## Usage

```typescript
import {
  healthMemoryItemSchema,
  InMemoryHealthMemoryStore,
  toMemoryItems,
  formatMemoryContext,
} from '@eir-open/health-memory';
```

See the [full documentation](https://github.com/Eir-Space/eir-open/tree/main/agent-harness) for API details and examples.
