# Assets Map

Use this file to pick the right bundled asset quickly.

## Brand

- `assets/brand/eir-aura.svg`
  Use for hero decoration, featured tiles, and social previews.

- `assets/brand/eir-rune.svg`
  Use for compact brand marks, favicon ideas, and badges.

## Web

- `assets/web/eir-tokens.css`
  Raw CSS custom properties for colors, spacing, radius, and motion.

- `assets/web/eir-app-shell.tsx`
  Starter structure for a headline, supporting panel, stats row, and content section.

## Selection Guide

- Need tokens only: use `eir-tokens.css`
- Need a quick React starting point: use `eir-app-shell.tsx`
- Need branded graphics without pulling a full design repo: use the SVGs
